## who am I?

not a tutorial collector.

someone who reads docs voluntarily and genuinely wonders:
*"why did they choose this architecture?"*
*"what breaks first when this scales?"*
*"what's actually happening under the hood?"*

the questions don't stop. the rabbit holes get deeper.
the coffee gets colder.

currently in the middle of a transition that matters to me:

```
developer  ──────────────────────────►  engineer
  (writes code)                    (understands systems)
       │
       └── 🚋here, moving fast
```

## what I actually think about

```java
// my brain, more or less
while (alive) {

    ask("why did they design it this way?");
    ask("what breaks at 10x traffic?");
    ask("how does this handle concurrency?");
    ask("one more abstraction layer... won't hurt");  // it hurt

    buildSomething();       // ambitious. probably overengineered
    shipIt();               // works on localhost 👍

    debugUntilItClicks();   // oh. THAT'S why that exists
```
